## Verified Findings

### 1. 🔴 Langflow — Unsafe Deserialization in Disk Cache (RCE)
- **File**: `src/backend/base/langflow/services/cache/disk.py:38`
- **CWE**: CWE-502 (Deserialization of Untrusted Data)
- **Code**: `return pickle.loads(item["value"])`
- **Impact**: Remote Code Execution if cache directory is writable by attacker
- **Exploitability**: Requires write access to diskcache directory (shared /tmp, path traversal, or multi-tenant deployment)
- **Bounty**: HackerOne → https://hackerone.com/ibm (7 business day response)
- **Status**: TO VERIFY — confirm cache directory permissions in default deployment

### 2. 🔴 Langflow — Code Compilation with User Input
- **File**: `src/backend/base/langflow/agentic/helpers/validation.py:254`
- **CWE**: CWE-94 (Code Injection)
- **Code**: `compile(ast.Module(body=tree.body, ...), "<string>", "exec")`
- **Impact**: Potential RCE if AST validation can be bypassed
- **Exploitability**: Medium — AST restrictions are in place but may have edge cases
- **Bounty**: HackerOne → https://hackerone.com/ibm
- **Status**: TO VERIFY — test AST bypass techniques

### 3. 🟡 Firecrawl — Missing Input Validation on Agent Endpoints (Path Traversal)
- **File**: `apps/api/src/controllers/v2/agent-cancel.ts:32`
- **File**: `apps/api/src/controllers/v2/agent-status.ts:35`
- **CWE**: CWE-20 (Improper Input Validation) / CWE-22 (Path Traversal)
- **Code**: `fetch(config.EXTRACT_V3_BETA_URL + "/internal/extracts/" + req.params.jobId)`
- **Impact**: Path traversal on internal API. `jobId` is NOT validated with UUID regex (unlike crawl-status.ts which does: `uuidReg.test(req.params.jobId)`)
- **Exploitability**: HIGH — direct, no auth bypass needed. Send crafted jobId like `../../admin/delete-all`
- **Evidence**: `crawl-status.ts:185` validates UUID, `agent-cancel.ts` and `agent-status.ts` do NOT
- **Bounty**: Check firecrawl SECURITY.md
- **Status**: READY TO REPORT — clear inconsistency, easy fix (add UUID validation)

### 4. 🟡 Open-WebUI — SSRF via Admin-Configurable Search URL
- **File**: `backend/open_webui/retrieval/web/yandex.py:77`
- **CWE**: CWE-918 (Server-Side Request Forgery)
- **Code**: `requests.post(yandex_search_url, headers=headers, json=payload)`
- **Config**: `routers/retrieval.py:1116` — admin sets URL via `form_data.web.YANDEX_WEB_SEARCH_URL`
- **Impact**: SSRF to internal services, cloud metadata (169.254.169.254)
- **Exploitability**: Requires admin access OR chain with XSS/CSRF to modify config
- **Status**: TO VERIFY — check if admin endpoint has CSRF protection

### 5. 🟡 Dify — Unsafe pickle.loads on Database Field
